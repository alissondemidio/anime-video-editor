# Roadmap

## M0: Working foundation
- Monorepo and CI
- Deterministic timeline and templates
- Editor preview and JSON export
- Validation tests

## M1: End-to-end local vertical slice
- Voiceover upload
- Media upload and tagging
- Local Whisper transcription
- Simple non-AI scene matching
- Timeline overrides and save/load
- Real MP4 export with FFmpeg/Remotion

## M2: Intelligence
- Local LLM provider (Ollama)
- Semantic media search and timestamp matching
- Confidence and source-of-match explanations
- Assisted scene replacement, effect presets
- Revision history

## M3: Product polish
- Waveform and timeline drag interactions
- Media bins and batch tagging
- Render queue with progress
- Packaged local desktop/runtime distribution
- Optional remote providers and cloud render, separately authorized
